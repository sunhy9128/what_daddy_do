## 1. 飞书文档概述

### 1.1 什么是飞书文档

飞书文档是一款**在线协作文档**工具，支持多人实时编辑、评论、@提及等能力。与 Word 等传统文档相比，飞书文档的核心优势在于：

- **实时协作** — 多人同时编辑，内容自动保存
- **云原生** — 无需手动保存，所有变更实时同步到云端
- **富媒体** — 支持插入表格、图片、视频、流程图、思维导图、代码块等
- **权限精细** — 可精确控制谁能查看、评论、编辑
- **多端同步** — 桌面端、Web、移动端实时同步

### 1.2 文档类型

| 类型 | 用途 | 特点 |
|------|------|------|
| **文档** | 日常协作、会议纪要、方案撰写 | 富文本，支持多种内容块 |
| **电子表格** | 数据收集、项目管理、排期表 | 类似 Excel，支持公式和函数 |
| **思维笔记** | 头脑风暴、知识整理 | 自由画布，支持思维导图 |
| **多维表格** | 项目跟踪、任务管理、CRM | 数据库式表格，支持多种视图 |
| **简报** | 团队汇报、演示 | 类 PPT 幻灯片式文档 |

## 2. 文档的创建与基础使用

### 2.1 创建文档

**入口路径：**

| 端 | 操作 |
|---|------|
| **桌面端** | 飞书主界面 → 左侧「文档」→ 右上角「新建」→ 选择文档类型 |
| **移动端** | 飞书 App → 底部「文档」→ 右下角「+」→ 选择文档类型 |
| **快捷键** | 桌面端任意位置 `⌘ + Shift + K`（Mac）/ `Ctrl + Shift + K`（Windows）快速新建 |

**从聊天创建：**
- 在聊天输入框点击「+」→「文档」→ 新建文档
- 或在聊天中发送 `/doc` 命令快速创建

### 2.2 文档界面说明

```
┌─────────────────────────────────────────────────┐
│  🔍 搜索  📋 目录  💬 评论  ⏱ 历史  👤 协作者  │  ← 顶部工具栏
├─────────────────────────────────────────────────┤
│  📄 标题区域（点击输入标题）                      │
├─────────────────────────────────────────────────┤
│  / 输入命令  或  + 插入内容块                     │
│                                                      │
│  █ 光标所在位置（正文区）                          │
│                                                      │
│  @ 提及同事  「」引用  代码  分割线  ✓ 任务列表 │
├─────────────────────────────────────────────────┤
│  ✏️ 编辑  💬 评论  👁 只读 ← 右上角模式切换       │
└─────────────────────────────────────────────────┘
```

### 2.3 基础操作

| 操作 | 方法 |
|------|------|
| **重命名** | 点击顶部标题栏直接编辑 |
| **全文搜索** | `⌘ + F`（Mac）/ `Ctrl + F`（Windows） |
| **插入内容** | 输入 `/` 唤出命令菜单，或点击行首 `+` |
| **调整顺序** | 拖拽内容块左侧的 `⠿` 图标 |
| **全文导出** | 右上角「⋯」→ 导出 → 选择 Word / PDF / Markdown |

## 3. 文档的编辑与排版

### 3.1 内容块类型

输入 `/` 可插入以下内容块：

```
文本类：          标题1~3 / 正文 / 引用 / 代码块 / 有序列表 / 无序列表
媒体类：          图片 / 文件 / 视频 / 网页书签 / 流程图 / 思维导图
表格类：          表格 / 看板 / 多维表格
高级类：          分栏 / 目录 / 时间轴 / 投票 / 表情包 / 公式 / 高亮块
协作类：          @ 用户 / 评论 / 任务列表
```

### 3.2 高级排版技巧

**分栏布局：**
- 输入 `/分栏` 创建左右分栏，拖拽分隔线调整比例
- 适用于对比展示、图文混排

**高亮块与信息框：**
- 输入 `/高亮块` 可创建带背景色的强调区域
- 支持多种颜色：信息蓝 / 成功绿 / 警告橙 / 错误红

**嵌入网页：**
- 输入 `/网页书签` 输入 URL，可将网页内容直接嵌入文档中预览

**目录自动生成：**
- 输入 `/目录` 即可根据文档中的标题层级自动生成可跳转目录

### 3.3 模板使用

飞书提供大量预设模板，新建文档时可在模板库中选择：

```
会议纪要模板    →  自动生成议程、待办事项、参会人
项目管理模板    →  甘特图、任务分配、里程碑
周报模板        →  本周工作 / 下周计划 / 需要支持
OKR 模板        →  目标 + 关键结果对齐
SWOT 分析模板   →  优势 / 劣势 / 机会 / 威胁
```

### 3.4 任务列表与待办

- 输入 `/任务列表` 创建带复选框的待办项
- 勾选完成项后自动标记为完成状态
- 可通过 `@` 将任务分配给具体同事
- 分配后的任务会出现在对方的飞书「任务」应用中

## 4. 文档的分享与协作

### 4.1 分享方式总览

| 方式 | 适用场景 | 操作方法 |
|------|---------|---------|
| **直接添加协作者** | 团队内部协作 | 右上角「分享」→ 输入成员名 / 部门 |
| **生成分享链接** | 跨团队 / 外部人员 | 右上角「分享」→「复制链接」 |
| **发送到聊天** | 即时通知 | 右上角「分享」→「发送到聊天」 |
| **嵌入飞书群** | 群内持续跟进 | 群输入框「+」→ 文档 → 选择文档 |
| **公开链接** | 全公司 / 公开分享 | 分享设置 →「互联网上获得链接的人可查看」 |

### 4.2 权限设置详解

点击右上角 **「分享」** 按钮进入权限设置面板：

```
┌─ 分享设置 ─────────────────────────────────────┐
│                                                  │
│  👤 添加协作者：输入姓名、部门或全员              │
│                                                  │
│  链接分享：https://xxx.feishu.cn/doc/xxx          │
│  ┌─ 权限范围 ──────────────────────────────────┐ │
│  │  ○ 仅协作者可访问                            │ │
│  │  ○ 组织中获得链接的人可阅读                  │ │
│  │  ○ 组织中获得链接的人可评论                  │ │
│  │  ○ 组织中获得链接的人可编辑                  │ │
│  │  ○ 互联网上获得链接的人可查看                │ │
│  └─────────────────────────────────────────────┘ │
│                                                  │
│  🔒 安全设置：                                    │
│  │  □ 禁止复制、导出、打印                       │
│  │  □ 设置有效期（1天/7天/30天/自定义）         │
│  │  □ 需要申请访问                              │
│  └─────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```

### 4.3 五种权限级别

| 权限级别 | 能力 |
|---------|------|
| **仅查看** | 可阅读文档内容，无法评论或编辑 |
| **可评论** | 阅读 + 添加评论 / 回复评论 |
| **可编辑** | 阅读 + 评论 + 编辑内容 |
| **可分享** | 编辑 + 可将文档分享给其他人 |
| **所有者** | 全部权限 + 转让所有权 + 删除文档 |

### 4.4 协作功能详解

**实时光标：**
- 其他协作者的编辑位置会显示彩色光标 + 头像
- 多人可同时在文档不同区域编辑，互不干扰

**评论功能：**
- 选中文字 → 弹出评论按钮 → 添加评论内容
- 支持 `@` 提及同事，对方会收到通知
- 评论可回复、可标记为「已解决」

**@ 提及：**
- 输入 `@` + 姓名可提及同事
- 被提及人收到飞书消息通知
- 支持 @ 文档（创建内部链接）、@ 日程、@ 会议

**动态通知：**
- 协作者进入文档时，右上角显示进入动画
- 文档内容变更实时广播
- 评论和 @ 提及通过飞书消息即时推送

### 4.5 外部人员协作

当需要与公司外部人员（客户、供应商等）协作时：

1. 右上角「分享」→「添加协作者」
2. 输入对方邮箱（需为飞书用户）
3. 设置权限为「可编辑」或「仅查看」
4. 可选：开启「安全设置」中的「禁止复制、导出、打印」

> **注意**：外部协作需要管理员开启「允许外部协作者」的团队设置。

### 4.6 文档嵌入群聊

**方法一：发送文档链接到群**
- 直接复制文档链接发送到群聊
- 群成员点击链接即可查看（需对应权限）

**方法二：固定到群快捷栏**
- 群设置 →「快捷栏」→ 添加文档
- 群成员可在群聊顶部快速访问

**方法三：作为群公告**
- 群设置 →「群公告」→ 插入文档链接
- 群公告自动展示文档标题和摘要

## 5. 文档的版本管理与历史

### 5.1 查看历史版本

- 点击顶部工具栏 **「⏱ 历史」** 按钮
- 左侧展示按时间排列的版本列表
- 选中某个版本，右侧预览该版本内容

### 5.2 版本操作

| 操作 | 说明 |
|------|------|
| **查看** | 点击版本号，预览该时间点的文档内容 |
| **恢复** | 点击「恢复此版本」，当前内容被替换为该版本 |
| **重命名** | 点击版本名旁的编辑图标，方便识别（如「初稿」「V2 评审版」） |
| **复制** | 将历史版本另存为一份新文档 |

### 5.3 自动保存机制

- 飞书文档**实时自动保存**，无需手动点击保存
- 每次编辑后约 1-2 秒自动落盘
- 网络断开时，本地编辑内容暂存，恢复后自动同步
- 版本历史保留 **近 90 天** 的编辑记录

### 5.4 建议：手动标记版本

对于重要文档（如方案评审、合同），建议手动标记版本：

```
操作：历史 → 当前版本 → 重命名 → 输入版本号
命名规范示例：v1.0_评审稿、v1.1_修改意见、v2.0_终稿
```

## 6. 飞书日程概述

### 6.1 什么是飞书日程

飞书日程（日历）是团队协作的核心工具之一，支持：

- 个人日程管理
- 团队日历共享
- 会议邀约与日程订阅
- 会议室与资源预定
- 跨日历视图对比

### 6.2 日程视图类型

| 视图 | 快捷键 | 适用场景 |
|------|--------|---------|
| **日视图** | `D` | 查看某一天的详细安排 |
| **周视图** | `W` | 查看当周整体安排（默认视图） |
| **月视图** | `M` | 查看整月概览 |
| **日程视图** | `A` | 按列表形式查看所有日程 |
| **年视图** | `Y` | 查看全年节假日与标记 |
| **多日对比** | - | 同时查看多人日历，快速找空闲时间 |

## 7. 日程的创建与管理

### 7.1 创建日程

**方式一：点击日历空白区域**
1. 在日历界面双击（或单击空白区域）
2. 弹出新建日程窗口
3. 填写标题、时间、参与人等信息

**方式二：从聊天创建**
1. 在聊天输入框点击「+」→「日程」
2. 或输入 `/meeting` 快速创建
3. 群成员会自动出现在可选参与人列表

**方式三：从文档创建**
1. 在文档中输入 `@` → 选择「日程」
2. 输入日程标题和时间
3. 文档中的日程可一键添加到日历

### 7.2 日程信息填写

创建日程时可填写以下信息：

```
┌─ 新建日程 ────────────────────────────────────┐
│                                                 │
│  标题 *         [ 输入日程标题 ]                │
│                                                 │
│  时间 *         [ 开始日期时间 ] → [ 结束时间 ]  │
│                 □ 全天事件                       │
│                                                 │
│  提醒           [ 10分钟前 ▼ ] [+ 添加提醒]     │
│                                                 │
│  参与人         [ 添加成员或群组 ]               │
│                 已添加：张三、李四                │
│                                                 │
│  地点           [ 输入地点或选择会议室 ]         │
│                                                 │
│  描述           [ 输入日程详情 / agenda ]       │
│                                                 │
│  日历           [ 个人日历 ▼ ]                  │
│                                                 │
│  重复           [ 不重复 ▼ ]                    │
│                 每天 / 每周 / 每月 / 工作日 /    │
│                 自定义                          │
│                                                 │
│  □ 开启视频会议（自动创建飞书会议）             │
│                                                 │
│  [取消]                          [保存]         │
└─────────────────────────────────────────────────┘
```

### 7.3 日程提醒

| 提醒方式 | 说明 |
|---------|------|
| **弹窗提醒** | 桌面端弹出通知窗口 |
| **消息提醒** | 飞书消息推送提醒 |
| **邮件提醒** | 发送邮件到绑定邮箱 |
| **短信提醒**（需开通） | 手机短信提醒 |

预设提醒时间：日程开始时 / 5 分钟前 / 10 分钟前 / 15 分钟前 / 30 分钟前 / 1 小时前 / 1 天前 / 自定义

### 7.4 重复日程（周期性事件）

支持多种重复规则：

```
不重复
每天           → 每日例会
每个工作日     → 站会
每周           → 周会（可选周几）
每两周         → 双周同步会
每月           → 月度汇报（可选第几周周几）
每年           → 生日提醒
自定义         → 满足特定规则的重复：每 N 天/周/月/年
```

设置重复后，可以：
- **编辑单次** — 只修改某一次日程
- **编辑全部** — 修改所有重复日程
- **仅删除单次** — 取消某一次但不影响其他

### 7.5 日历分组与颜色

- 飞书支持创建**多个日历**（个人日历、项目日历、部门日历等）
- 每个日历独立设置**颜色**，便于区分
- 日历可**显示/隐藏**，只展示你需要看的内容

```
如何创建新日历：
左侧日历列表 → 底部「+ 新建日历」→ 输入名称和颜色
```

## 8. 日程的分享与邀请

### 8.1 邀请参与人

**添加个人参与人：**
1. 创建/编辑日程 → 参与人 → 输入姓名
2. 支持模糊搜索：输入拼音首字母即可
3. 添加后，对方会收到日程邀请通知

**添加群聊参与人：**
1. 参与人 →「从群聊导入」
2. 选择一个群，该群所有成员自动添加
3. 新成员加入群后，自动收到日程邀请

**添加外部参与人：**
1. 参与人 → 输入对方邮箱
2. 对方即使非飞书用户，也会收到邮件邀请
3. 外部参与人可通过邮件回复接受/拒绝

### 8.2 参与人状态

被邀请人会收到日程通知，可在日历中操作：

| 状态 | 图标 | 含义 |
|------|------|------|
| **待回复** | ⏳ | 尚未处理邀请 |
| **接受** | ✅ | 确认参加 |
| **待定** | ❓ | 可能参加 |
| **拒绝** | ❌ | 无法参加 |
| **未回复** | — | 未查看邀请 |

> **提示**：创建者可以随时查看参与人状态，了解参会情况。

### 8.3 日程链接分享

**生成日程链接：**
1. 打开日程详情
2. 点击「分享」→ 复制链接
3. 对方点击链接即可查看日程详情

**嵌入到文档：**
1. 在文档中输入 `@` → 选择日程
2. 文档中直接显示日程卡片
3. 其他人在文档中可「添加到我的日历」

### 8.4 订阅日历（日历分享）

**什么是日历订阅：**
将你的日历分享给他人，对方可直接在你的日历上查看你的空闲/忙碌状态，无需逐个邀请。

**分享日历的两种模式：**

| 模式 | 对方能看到 | 适用场景 |
|------|-----------|---------|
| **仅查看空闲/忙碌** | 哪些时段有安排，不显示详情 | 跨部门约时间 |
| **查看所有详情** | 日程标题、时间、参与人等全部信息 | 团队共享日历 |

**操作步骤：**
1. 左侧日历列表 → 右键点击日历 →「分享设置」
2. 选择权限模式（仅闲忙 / 可查看详情）
3. 添加成员或生成分享链接

### 8.5 会议室与资源预定

1. 创建日程时，在「地点」中选择「预定会议室」
2. 按楼层/容量/设备筛选可用会议室
3. 确认后，日程自动关联该会议室
4. 其他人在约同一时段时可见会议室已被占用

**可选资源：** 会议室、投影仪、电话设备、白板等（由管理员配置）

### 8.6 视频会议集成

- 创建日程时勾选「开启视频会议」
- 日程自动关联飞书会议链接
- 参与人点击即可加入
- 日程前 5 分钟，参与人自动收到加入会议提醒

## 9. 日程群组与订阅

### 9.1 团队日历

**创建团队日历：**
1. 左侧日历列表 →「+ 新建日历」
2. 输入名称（如「研发团队日历」「市场活动日历」）
3. 设置共享范围：仅部分成员 / 整个部门 / 全公司

**团队日历使用场景：**
- 部门排班表
- 项目里程碑
- 团队休假时间
- 活动排期

### 9.2 订阅外部日历

支持导入外部日历（ICS 格式）：

```
支持的来源：
- Google Calendar
- Outlook Calendar
- Apple iCloud Calendar
- 任何支持 ICS 协议的日历
```

**导入方法：**
1. 左侧日历列表 → 底部「+」→「导入日历」
2. 填入 ICS 订阅地址或上传 ICS 文件
3. 命名日历并设置颜色
4. 外部日历变更会自动同步

### 9.3 日历对比（多人闲忙查询）

**用途：** 快速找到多人共同的空闲时间，安排会议。

**操作方法：**
1. 日历右上角「☰」→「日历对比」
2. 勾选需要对比的人（最多 10 人）
3. 系统自动高亮显示所有人的空闲时段
4. 点击空闲时段一键创建日程

## 10. 常见问题与最佳实践

### 10.1 常见问题

**Q：文档忘记保存了怎么办？**
A：飞书文档自动保存，无需手动操作。可以通过「历史」查看所有历史版本并恢复。

**Q：不小心删除了重要文档？**
A：进入「文档」→ 左侧「回收站」→ 找到文档 → 还原。回收站保留 30 天。

**Q：分享链接打不开？**
A：检查权限设置是否允许对方访问。如果设置了「仅协作者」，需要先添加对方为协作者。

**Q：参与人收不到日程邀请？**
A：确认对方是否在组织通讯录中。外部邮箱需管理员开通外部协作权限。

**Q：如何查看谁修改了文档？**
A：点击「⏱ 历史」，每个版本会显示该版本的修改人姓名和修改时间。

**Q：日程冲突怎么办？**
A：飞书日历会自动检测并提示冲突。建议使用「日历对比」功能找到共同空闲时间。

### 10.2 文档使用最佳实践

**文档组织规范：**

```
推荐目录结构：
📁 部门文档
  📁 项目 A
    📄 需求文档
    📄 技术方案
    📄 会议纪要
  📁 项目 B
    📄 项目计划
    📄 周报
```

- 文档标题使用 **「类型_项目_日期」** 格式，方便搜索
- 使用 **「目录」** 块让长文档有清晰结构
- 关键内容使用 **「高亮块」** 突出显示
- 定期清理回收站，释放空间

### 10.3 日程使用最佳实践

- **提前设置日程提醒** — 重要会议提醒时间设为提前 15-30 分钟
- **创建团队日历** — 避免将个人日程与团队日程混在一起
- **随时更新参与人状态** — 无法参加请及时拒绝，方便组织者调整
- **善用「日历对比」** — 约多人会议前，先查共同空闲时间
- **关联视频会议** — 减少沟通成本，一键入会
- **写好日程描述** — 让参会人提前了解会议议程

### 10.4 协作规范建议

| 场景 | 建议 |
|------|------|
| **文档多人编辑** | 使用「@」明确分配任务段落 |
| **文档审阅** | 使用评论功能，逐条反馈，避免直接修改 |
| **会议安排** | 使用日程邀请，关联文档和视频会议 |
| **项目排期** | 创建团队日历，共享项目里程碑 |
| **周报汇总** | 创建周报模板，全员统一格式 |
